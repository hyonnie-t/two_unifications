# two_unifications

세계사 주제31 「이탈리아·독일의 통일 비교」 웹앱 (2학년, 교과서 152·154·155쪽, 1차시).

- 파일: `index.html` / `style.css` / `data.js`(카드·상자·힌트·낱말 풀이) / `app.js`(로직) / `logic.js`(카드 순서 판정). 빌드 단계 없음.
  `focus_guard.js`·`draft_guard.js`·`glossary.js`는 history26 `snippets/`에서 복사한 것(6c4653a 시점). 순서 끌기는 cdnjs의 SortableJS 1.15.0.
- 미리보기: `?preview=1` (저장 없음). 자동채움: `?sid=20512&name=이름`.
- 흐름: ① 찾기 1/2 이탈리아 → ② 찾기 2/2 독일 → ③ 비교(두 줄 나란히, 같은 점·다른 점) → ④ 쓰기(① 2011년 기준 지금도 국민 국가일까: 선택 후 입력칸 열림 + ② 북부·남부 불만을 줄일 방법: 선택 없이 바로 쓰기) → ⑤ 마무리(제출·글 복사·패들렛 링크).
- 카드 순서: 드래그(☰ 손잡이) + ▲▼ 버튼. 틀리면 "n쪽을 다시 읽어 봐"만 보여 주고, 3번 틀리면 정답 순서를 보여 준 뒤 넘어간다.
- 포털 커리큘럼 관리에 activity id 하나 등록: `31차시_이탈리아_독일_통일` (`app.js`의 `CONFIG.GAME_NAME`, 임시 이름 — 바꾸면 이 값도 같이).
- 저장은 기존 기본 제출 경로만 쓰며 백엔드·시트 구조 변경 없음. `reflection`(G열) = [비교]+[지금도 국민 국가일까]+[해결] 합본, `choiceSummary` = 두 선택.
  글 복사 = 쓰기 두 칸만.
- 패들렛 링크는 백엔드 `?mode=curriculum`의 학년별 포트폴리오 링크를 불러온다(반 정보가 든 링크라 레포에 적지 않는다).
- 시험: `node verify.mjs`(카드 순서 판정), `node ../history26/snippets/vocab_check.mjs .`(어휘 풀이 누락 0건).
- 카드·상자·국민 국가 뜻은 교과서 본문과 쪽수까지 맞춘 것이라 바꾸지 않는다. 바꿔야 하면 효니에게 먼저 묻는다.
